## Listando a atividade

## O que e um Git?
É um sistema de controle de versao distribuído e gratuito que registra todas as alterações feitas em arquivos e códigos de um projeto ao longo do tempo. 

## O que e um GitHub?
É uma plataforma de hospedagem de código-fonte e arquivos na nuvem que usa o sistema de controle de versão Git.

## O que e um push
O comando git push serve para enviar as alterações feitas no seu código local (no seu computador) para um repositório remoto (como o GitHub ou GitLab).

## O que e um pull?
No controle de versão com Git, o comando git pull serve para baixar e atualizar o seu computador com as modificações mais recentes que outras pessoas fizeram no repositório remoto (como no GitHub).
